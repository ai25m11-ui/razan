# شطرنج البحر العميق - متعدد اللاعبين 🌊♟

لعبة شطرنج بتصميم بحري تفاعلي مع نظام غرف عبر الإنترنت، مؤثرات صوتية توليفية، ومؤثرات بصرية رائعة (تأثير نبضة سونار وغضب الكراكن).

## الملفات الموجودة:
- `index.html`: ملف الواجهة الذي يحتوي على تصميم اللعبة ومنطقها بالكامل، بالإضافة للمؤثرات الصوتية.
- `server.js`: سيرفر Node.js + Socket.io يدير الغرف ويربط اللاعبين معاً.
- `package.json`: يحتوي على أسماء المكتبات المطلوبة لتشغيل السيرفر.
- `.gitignore`: لتجاهل مجلد `node_modules` عند رفع الكود.

---

## 🚀 كيفية رفع اللعبة مجاناً ليلعبها أي شخص:

أسهل طريقة لرفع اللعبة وجعلها متاحة على الإنترنت هي عبر خدمة مثل **Render** أو **Railway**:

### الخطوة 1: رفع الكود إلى GitHub
1. قم بإنشاء حساب في [GitHub](https://github.com/).
2. أنشئ مستودعاً جديداً (New Repository).
3. ارفع ملفات اللعبة التالية فقط إليه:
   - `index.html`
   - `server.js`
   - `package.json`
   - `package-lock.json` (إن وُجد)
   *(ملاحظة: لا تقم برفع مجلد `node_modules` أبداً)*

### الخطوة 2: استضافة السيرفر عبر Render
1. سجل دخول في موقع [Render.com](https://render.com/) باستخدام حسابك في GitHub.
2. انقر على **New** ثم اختر **Web Service**.
3. قم بربط مستودعك الذي أنشأته في الخطوة السابقة.
4. اترك جميع الإعدادات كما هي:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. اضغط على **Create Web Service**.
6. سيبدأ الموقع برفع لعبتك وخلال دقائق سيعطيك رابطاً يمكنك مشاركته مع أي شخص للعب معاً!
